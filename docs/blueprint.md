# **App Name**: Zenith Salon Booking

## Core Features:

- User Authentication: Allow users to register and log in, storing user data temporarily using state/context.
- Service Listing: Display a list of salon services with images, names, estimated duration, and prices.
- Service Details: Show detailed information for each service, including description, duration, price, ratings, and testimonials.
- Booking Form: Present a modal dialog with a booking form, including fields for date, time, customer name, and additional notes.
- Booking Confirmation: Store booking data temporarily using state or context, and display a success message upon booking.
- My Bookings: List all bookings made by the user, showing service name, date/time, and booking status, visualized with a progress bar.
- AI Style Advisor: Suggest salon services based on user-provided images of current hair style and desired change. Use the information as a tool to enhance your recommendation, without relying solely on AI.

## Style Guidelines:

- Primary color: Deep purple (#673AB7) to evoke sophistication and beauty.
- Background color: Light lavender (#F3E5F5), a desaturated variant of the primary color.
- Accent color: Pink (#E91E63) for a vibrant contrast and call to action.
- Font: 'Belleza' sans-serif for headlines, paired with 'Alegreya' serif for body text.
- Use elegant, minimalist icons related to salon services.
- Employ a clean and responsive layout to ensure readability and usability on different screen sizes.
- Incorporate subtle animations to provide feedback and enhance user experience, such as transitions and loading indicators.
